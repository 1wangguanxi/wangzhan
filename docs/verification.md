## 当前交付

已移除 Next.js App Router、SSR / ISR、官网 API 代理、Go 服务、PostgreSQL 配置、管理后台及共享管理契约。已合并为单一 npm 项目，源码、静态内容及依赖配置集中维护。页面由 esbuild + React 在构建时生成，部署目录为根目录 `dist/`。

## 目录与代码整理

- 将原官网和内容 workspace 合并为根目录单一 npm 项目：`src/`、`public/`、`scripts/`，只保留一份包配置与 TypeScript 配置。
- 删除 38 个迁移残留空目录和约 81 MiB 的旧 Next.js 构建缓存、TypeScript 增量缓存。历史 `.runtime/` 数据与参考存档保留。
- 页面改用明确的组件名称，移除未使用的导入、参数和非 FAQ 页上的 FAQ Provider。
- 统一项目路径与页面清单来源，增加 Prettier 配置、未使用代码检查和 `npm run check` 一键验证。
